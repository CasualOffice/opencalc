# The oracle corpus: one formula per line, evaluated by OpenCalc and by
# LibreOffice Calc and compared.
#
# Lines starting with `#` are comments. A line may end with a marker:
#
#   <formula>            compared; a difference fails the run
#   <formula>  @differs: <reason>
#                        compared and *expected* to differ, with the reason
#                        recorded. A difference is reported and does not fail;
#                        an unexpected *agreement* does fail, so a marker that
#                        stops being true gets removed rather than rotting.
#
# Formulas may reference the fixture block, which the harness writes into every
# generated workbook:
#
#   C1:C10   1, 2, 3 … 10
#   D1:D10   10, 20, 30 … 100
#   E1:E5    "alpha", "beta", "gamma", "delta", "epsilon"
#   F1:F5    TRUE, FALSE, TRUE, FALSE, TRUE
#   G1:G5    2.5, -3.5, 0, 1e10, -0.25
#   H1:H5    "10", "-2.5", "abc", "", "3"      (text that looks numeric)
#
# Keep each line a single expression. The point of the corpus is breadth of
# *semantics*, not of syntax.
