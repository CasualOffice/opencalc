OpenCalc

A deterministic, embeddable spreadsheet engine written in Rust — it reads and writes .xlsx, holds the workbook in a normalized editable model, calculates it, and lays out and renders a virtualized grid, for native, WebAssembly, and headless hosts.

Everything below runs entirely in your browser — the same engine that runs natively in a Tauri desktop app, compiled to WebAssembly. Nothing is uploaded.

View on GitHub Try the demo

Loss-aware

Content the model doesn't represent is preserved or reported — never silently dropped.

Deterministic

Same input + version ⇒ same model, values, layout, and bytes. Every layer is golden-testable.

Embeddable

No mandatory DOM, server, or UI framework. Rust, wasm32, desktop, and headless alike.

Built for scale

Designed for 1M+ cells, 60 fps scrolling, and sub-50 ms recalculation.
