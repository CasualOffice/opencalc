OpenCalc on your desktop.

The same engine as the web editor, in a native window: your files stay on your machine, it opens .xlsx by double-click, and it works with no network at all.

This is an alpha. The builds are unsigned, which means every operating system will stop you the first time. Each one takes a single step, below — and the messages they show are misleading enough to be worth reading first.

Your computer will stop you once. Here is why, and what to do.

Signing an application means paying Apple or a certificate authority to vouch for it. This project has not done that yet, so each operating system treats these builds as being from an unknown source. That is a fair thing for them to do — and it means you should only ever run this step on a file you downloaded from the link above, having checked it against the published checksum if you want to be careful.

macOS — “OpenCalc is damaged and can’t be opened”

It is not damaged. That is the wording macOS uses when it cannot validate a signature, and it is the same message you would get for a genuinely corrupt file — which is why it is worth being explicit about. Drag OpenCalc to your Applications folder, then run these two lines in Terminal: 

xattr -dr com.apple.quarantine /Applications/OpenCalc.app
codesign --force --deep --sign - /Applications/OpenCalc.app

The first line removes the “downloaded from the internet” flag. The second re-signs the app on your own machine with an ad-hoc signature, which is what actually clears the damaged message: builds of 0.0.0 carry a signature from the linker that seals no contents, and macOS rejects a bundle whose signature does not describe what is inside it. Releases after 0.0.0 do this at build time, so only the first line will be needed.

Apple Silicon only. The 0.0.0 .dmg is built for arm64 and will not run on an Intel Mac. If you are on an Intel Mac, use the web editor for now — it is the same engine.

Windows — “Windows protected your PC”

SmartScreen hides the button by default. Click More info, then Run anyway. There is no command to run and nothing to change in your settings.

Linux

The .deb installs normally:

sudo dpkg -i OpenCalc_0.0.0_amd64.deb

The AppImage needs the executable bit before it will run:

chmod +x OpenCalc_0.0.0_amd64.AppImage
./OpenCalc_0.0.0_amd64.AppImage

Checking what you downloaded

Nothing here is signed, so a checksum is the only thing you can actually verify. Download SHA256SUMS.txt into the same folder and run: 

shasum -a 256 -c SHA256SUMS.txt --ignore-missing
