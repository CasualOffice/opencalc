Theme

Chrome

The app header is off by default when embedded — the brand mark and settings gear belong to this project's own page, not to your product.

Engine

Language

Keyed by command id, which comes from the English label — so translating never renumbers the command API. A key with no translation falls back to English, which is why only part of this menu changes.

Isolation

Applies Comic Sans, right-to-left, uppercase, magenta controls, an inverted canvas filter and --bg: hotpink to the page. The editor is unaffected: a shadow boundary stops selectors, and all: initial stops the inherited properties that cross it.
