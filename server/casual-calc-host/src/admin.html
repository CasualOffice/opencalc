OpenCalc admin

Changeable while running

Applied to the next session anybody opens. Connections already open keep the socket they have — a live socket cannot be re-pointed without dropping it, and dropping it to apply a setting is worse than waiting.

Restart-only

Not editable here, and that is deliberate rather than unfinished. A new signing secret invalidates every token in flight; a new bind address is a different server; a node changing identity mid-lease is exactly the zombie the epoch fence exists to stop. These are environment variables, and changing one means restarting the thing it configures.
